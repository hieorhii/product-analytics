# Product Analytics & Churn Prediction

## О проекте
Проект, симулирующий задачи Data Scientist. Включает в себя проверку продуктовых гипотез методами математической статистики и прогнозирование оттока пользователей (Churn).

## Стек технологий
* **Data Processing & SQL:** DuckDB, Pandas, NumPy.
* **Math & Stat:** SciPy, метрики A/B тестирования (T-Test, Bootstrap).
* **Machine Learning:** Scikit-learn (`RandomForestClassifier`).
* **Data Visualization:** Power BI, Matplotlib, Seaborn.

## Ключевые этапы реализации
1. **Генерация данных (`generate_data.py`):**
   Генерация датасета на 10,000 транзакций с разметкой групп (A/B) и применением экспоненциального распределения торговых объемов.
2. **Продуктовые метрики (DuckDB SQL):**
   Расчет базовых показателей платформы — ARPU, LTV и комиссионной выручки.
3. **Когортный анализ (Retention):**
   Построение Retention-матрицы удержания пользователей по месяцам.
4. **Проверка гипотез (A/B Test):**
   Оценка статистической значимости изменения комиссий между группами A и B с применением T-теста Уэлча и расчета доверительного интервала методом Bootstrap (95% CI).
5. **Предсказание оттока (Machine Learning):**
   Обучение модели Random Forest. Оценка качества модели по метрике ROC-AUC, анализ важности признаков (Feature Importance).
6. **Дашбординг (Power BI):**
   Сборка интерактивного Executive-дашборда (файл `dashboard.pbix` / скриншот `dashboard.png`).
